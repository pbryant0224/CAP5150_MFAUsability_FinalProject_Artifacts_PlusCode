# MFA Usability Final Project | CAP 5150

This repository contains the materials for my CAP 5150 final project, which focuses on the usability of Multi-Factor Authentication (MFA).

The goal of this project was to explore how MFA impacts the user experience, identify common usability challenges, and look at ways to make authentication easier without compromising security.

### What's Included
- Project data and supporting research materials
- Usability testing artifacts
- Overleaf (LaTeX) source code for the final report
- Additional project files and documentation

All materials are organized here for easy access, review, and reference.

**Course:** CAP 5150 | University of Central Florida  
**Project:** MFA Usability Final Project
